# 🍄 基於 YOLOv11n 之結構光香菇自動偵測系統

本專案利用輕量化目標偵測模型 **YOLOv11n**，針對結構光（Structured Light）照明下之香菇影像進行自動化目標定位，作為後續 3D 表面形貌重建與品質（熟度、裂紋）分級之前處理基礎。

## 📂 專案檔案說明
* `best.pt`：訓練完成之 YOLOv11n 最佳模型權重檔（輸入解析度 `640×640`）
* `data.yaml`：資料集類別與路徑設定檔（單一類別：`mushroom`）
* `train.py`：模型訓練主程式
* `predict.py`：批次影像推論與框選辨識程式
* `open.py` / `result.py`：影像開啟與評估結果檢視輔助腳本

## 📊 模型量化評估成績
於本地端 **NVIDIA RTX 5060 Ti GPU** 環境訓練 100 輪，驗證集表現如下：
* **mAP50**: `0.995`
* **mAP50-95**: `0.990`
* **Precision (精確率)**: `0.997`
* **Recall (召回率)**: `1.000`
* **推論速度**: 單張影像約 `7~10 ms`

## 🔍 跨光源實測與泛化能力分析
1. **結構光照明測試**：主體辨識信心分數達 `0.93~0.94`，邊界框緊密貼合菌傘輪廓。
2. **無結構光（一般白光）盲測**：額外以 20 張未參與訓練之光滑表面香菇進行測試，達成 **100% 檢出率**（信心分數 `0.94~0.95`），驗證模型具備良好之幾何輪廓泛化能力。
